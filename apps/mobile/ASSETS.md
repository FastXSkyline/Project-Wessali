# Mobile visual assets

## 3D service and navigation illustrations

The service illustrations and supporting 3D UI icons come from **3Dicons V1** by Vijay Verma (@realvjy).

- Collection: https://3dicons.co/collection/b68cf8-v1
- Creator / project: https://github.com/realvjy/3dicons
- License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/

The assets are human-made Blender renders from the public collection; no AI-generated icons are used in the app.

The app references the pack's public transparent color renders for the freight, roadside, water, location, clock, and information icon roles. They are WebP files, so the mobile UI renders them with Expo Image (the SDK 58-compatible `expo-image` package) for iOS and Android support.
